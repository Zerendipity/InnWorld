# Crónica de Esthelm

Player-facing site for the Innworld campaign (Spanish). Published with GitHub Pages.

- Text lives in `_Site/content/` (one Markdown file per entry). Editing a file here and committing rebuilds the site.
- Images are pre-optimized in `_Site/media/`.
- Build locally: `pip install -r _Site/requirements.txt && python _Site/build.py` (output in `_Site/dist/`).
- Only player-safe text belongs in this repo. The GM notes live elsewhere.

See `_Site/README.md` for the entry format.
